Privacy Policy

This describes what data the Lockdown Discord bot ("Lockdown," "the bot") collects, why, and how it's handled.

§ 01

What Gets Collected

Lockdown only collects what a given command or feature needs to work:

DataWhy
Discord user & server IDsRequired by Discord's API for every command; used to attribute actions and settings to the right person/server.
Message content (specific commands only)Only when you directly use a command that needs it — e.g. talking to the AI chat feature, or content you submit to a moderation/case-log command.
Economy balances & inventoryPowers the bot's economy commands (balance, shop, etc.).
Moderation records (warns, cases, tickets)Server moderation history, visible to that server's staff.
Whitelist / staff role listsTracks who has elevated command access.

Lockdown does not read or log ordinary server messages it isn't directly commanded to act on.

§ 02

Third-Party Processing

A few features send your input to a third-party API to work:

  • AI chat — messages you send to the bot's chat feature are sent to Groq's API to generate a reply. They are not sold or used for anything beyond producing that reply.
  • Music/profile lookups — commands that pull data from services like Last.fm send only the username or query you provide.
§ 03

Storage & Retention

Data is stored locally on the server Lockdown runs on (not sold, shared, or handed to advertisers). It's kept for as long as it's useful to the feature it belongs to — e.g. your economy balance persists until you ask for it to be reset; moderation logs persist per that server's own retention needs.

§ 04

Restricted Lookup Tools

Lockdown includes owner-only administrative and diagnostic tools that aren't exposed to server members or staff. These exist for the operator's own security/administrative use and are not used to look up ordinary members on request.

§ 05

Your Rights

You can ask for your data (economy balance, whitelist entries, stored preferences) to be shown or deleted at any time by contacting the developer — see below.

§ 06

Children's Privacy

Lockdown is intended for use in accordance with Discord's own Terms of Service, which require users to be at least the minimum age set by Discord. It does not knowingly collect data from users below that age.

§ 07

Changes to This Policy

This policy may be updated as Lockdown's features change. Material changes will be reflected here with an updated effective date.

§ 08

Contact

Data requests or privacy questions can be sent to the developer on Discord: @kochajacy.
